# Mathematical Foundations of Statistics and Learning

A book in progress that develops probability, statistics, and learning theory through definitions, theorems, proofs, and examples. The first milestone is a fully specified autoregressive transformer.

- [Manuscript](foundations_2026_11_11_14_59.tex)
- [Book plan](book-plan_2026_11_11_13_55.tex)

The draft covers Chapters 1–5, through Fisher information and the Cramér–Rao bound. Both LaTeX documents are standalone. Open either in a LaTeX editor or build it with `latexmk -pdf`.

Run `python3 book_refs.py <label>` to find a definition and its explicit cross-references. Run `python3 backup_pdf.py <section-label>` to save a timestamped copy of a fresh manuscript build to `backups/`.
